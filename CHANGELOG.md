# Changelog

## 0.3.0 - 2026-10-31

- Define connected accounts as ongoing interaction channels for the user's existing AI.
- Extend the workflow through receiving, acting, responding, and resuming; distinguish a login or test send from a running channel.
- Focus the public introduction and roadmap on user interactions and operation. Move individual validation reports out of the current public tree into local development records.
- Keep implementation and tool selection with the user's AI; add no required runtime or platform adapter.

## 0.2.0 - 2026-10-31

- Center ACA on one self-contained, model- and host-independent workflow.
- Remove model-specific installers, mandatory record schemas, and unnecessary framework dependencies.
- Let the user's AI choose tools, implementation, and connection storage.

## 0.1.0 - 2026-10-31

- Initial skill packaging and validation infrastructure, superseded by the method-first direction in 0.2.0.
