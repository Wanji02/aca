# M1: skill and connection-record validation

Date: 2026-10-31. Package version: 0.1.0. Record contract: 1.0.0.

## Checked locally

| Check | Environment and observed scope |
| --- | --- |
| Skill discovery | Codex CLI `0.165.0-alpha.1.2`, Windows: the native app-server `skills/list` endpoint found `aca-connect`, enabled, with repository scope in an isolated project. |
| Codex copy layout | Complete bundle copied to `.agents/skills/aca-connect`, including schema, guide, template, and UI metadata. |
| Claude Code copy layout | Complete bundle copied to `.claude/skills/aca-connect`; this is a file-layout check, not a Claude runtime result. |
| Record and installation tests | 33 automated tests passed on Windows with Node.js 24.16.0. |
| Skill manifest | The local skill-creator validator accepted the skill frontmatter and instructions. |

The tests cover missing verification, stale context revisions, unsupported versions, invalid dates, duplicate capabilities, ambiguous outcomes, persistent-resource ownership, non-mutating validation, input error handling, installation without overwriting existing skills, linked destination rejection, and preservation of unrelated files.

The native discovery probe made no model turn, platform call, or device action. It used an isolated project and retained only ACA's own discovery metadata. It did not install the skill globally or modify a live assistant's personality or memory.

## Reproduce the structural checks

```sh
npm ci --ignore-scripts
npm run check
npm test
npm run validate:record -- examples/records/fixture-verified.json
```

The last command validates a synthetic declaration; it does not connect a service. `examples/records/invalid-stale.json` must exit with code 1.

Project-local installation can be tested in a temporary workspace using `scripts/install-skill.mjs`. Start the actual host in that workspace and confirm the skill appears before reporting host discovery. A correct directory alone is insufficient evidence.

## Not established by these checks

- Claude Code runtime discovery: the host was not installed in the local test environment.
- Skill invocation quality, autonomous connection success, or improvement over an agent without ACA.
- Real platform/device compatibility, media playback, message delivery, or recovery of a real connection.
- Truth or availability of evidence referenced in a record. The checker deliberately does not fetch it.
- CI results on other operating systems until the corresponding workflow runs pass.

Windows/Linux CI definitions accompany this release. Their results are recorded in GitHub Actions independently of the local checks above. M2 will evaluate real task behavior and connection outcomes.
