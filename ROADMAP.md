# Roadmap

## Available in this initial release

- English project introduction.
- A host-neutral Connect workflow.
- A local connection-record template and documentation.
- Evaluation scenarios and contribution guidance.

## Next

1. Run the same workflow on a network target and a device target, without hidden prewritten adapters.
2. Publish sanitized reproducible reports, including failed routes and recovery.
3. Compare behavior across tool-enabled agent hosts.
4. Turn repeated setup and verification steps into small reusable helpers.
5. Add host-specific packaging only where it improves the workflow.

The direction is broad connection coverage with a small common workflow. Platform clients, audio models, device firmware, and personal memory systems are not mandatory core dependencies.
